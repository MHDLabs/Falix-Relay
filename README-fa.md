# 🛰️ Falix-Relay

**Keep it simple :) — MHDLabs**

[🇬🇧 English](README.md) · [راهنمای راه‌اندازی](docs/README-fa.md)


Falix-Relay یک رلهٔ سبک و بدون پنل برای **VLESS + WebSocket** است که از هستهٔ رسمی [Xray-core](https://github.com/XTLS/Xray-core) استفاده می‌کند. هدف پروژه، اجرای ساده روی Falix یا هر میزبان سازگار با کانتینر است.

نه پنل وب، نه دیتابیس کاربران، نه سهمیه و نه آمار مصرف؛ فقط یک ورودی و یک UUID.

## ✨ امکانات

- 🔐 یک کلاینت VLESS با UUID تنظیم‌شده از طریق `XRAY_UUID`
- 🌐 انتقال WebSocket با مسیر قابل تنظیم از طریق `WS_PATH`
- 🔌 پورت TCP قابل تنظیم از طریق `PORT`
- 📦 ایمیج Docker سبک بر پایهٔ باینری رسمی Xray
- 🔒 اجرای برنامه با کاربر غیر root و بررسی checksum فایل انتشار Xray
- 🧰 فرمان‌های `check` و `version` برای بررسی اولیه

نسخهٔ فعلی از Xray-core **v26.10.21** استفاده می‌کند. پنل، دیتابیس، سیستم حساب کاربری، مدیریت سهمیه، داشبورد مصرف یا موتور پروکسی دوم در پروژه وجود ندارد.

## 🚀 نکات استقرار روی Falix

Falix برای هر سرور یک پورت عمومی اختصاص می‌دهد. مقدار متغیر محیطی `PORT` در این پروژه باید دقیقاً برابر پورت اختصاص‌یافته در بخش **Network → Ports** باشد. نسخهٔ فعلی برنامه متغیر `PORT` را می‌خواند و به‌صورت خودکار از متغیر `SERVER_PORT` در Falix استفاده نمی‌کند.

ورودی Xray روی `0.0.0.0` گوش می‌دهد و مسیر پیش‌فرض WebSocket برابر `/relay` است.

اتصال از طریق آدرس و پورت خام Falix با WebSocket معمولی امکان‌پذیر است. برای WebSocket امن (WSS)، سرویس را پشت Reverse Proxy خود Falix قرار بده. ساب‌دامین DNS به‌تنهایی TLS ایجاد نمی‌کند.

> [!WARNING]
> **استفاده از سرورهای رایگان Falix برای اجرای نرم‌افزار VPN/Proxy یا انتقال ترافیک دیگران مجاز نیست.** این محدودیت در سیاست استفادهٔ قابل قبول فعلی Falix ذکر شده است. این پروژه را روی سرور Free اجرا نکن. برای سایر پلن‌ها نیز پیش از استقرار، قوانین همان پلن را بررسی کن.

## ⚙️ تنظیمات

| متغیر | ضروری | پیش‌فرض | توضیح |
|---|---:|---|---|
| `XRAY_UUID` | بله | — | UUID خصوصی تنها کلاینت VLESS |
| `PORT` | خیر | `8080` | پورت TCP؛ باید بین `1024` تا `65535` باشد |
| `WS_PATH` | خیر | `/relay` | مسیر WebSocket |

برای ساخت UUID خصوصی در Linux:


```sh
cat /proc/sys/kernel/random/uuid
```

## 📦 ایمیج آماده

GitHub Actions ایمیج چندمعماری برای Linux **amd64** و **arm64** می‌سازد و در GHCR منتشر می‌کند:


```sh
docker pull ghcr.io/mhdlabs/falix-relay:latest
```


برای دریافت بدون ورود، Package باید در GitHub Packages روی حالت Public باشد.

## 🔐 شبکه و امنیت

در پیکربندی فعلی، Xray داخل کانتینر WebSocket معمولی را دریافت می‌کند و خودش TLS را خاتمه نمی‌دهد. برای WSS از Reverse Proxy دارای TLS استفاده کن. صرفاً داشتن یک نام دامنه به معنی رمزنگاری اتصال نیست.

پروژه دادهٔ پایدار داخل کانتینر ذخیره نمی‌کند. پیش از جایگزینی یا حذف سرویس، UUID خصوصی را در محل امن نگه دار.
